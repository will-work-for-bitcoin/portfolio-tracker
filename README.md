# 💰 Portfolio Tracker — Multi-Asset Crypto Portfolio Tracker

Track your cryptocurrency portfolio with real-time prices, P&L, and performance metrics. Supports BTC, ETH, SOL, LTC, and more.

## Features
- ⚡ Zero dependencies (pure Python 3.7+)
- 📊 Real-time portfolio valuation
- 💰 P&L tracking with buy prices
- 📤 JSON export for analysis
- 🔄 Continuous monitoring

## Installation
```bash
git clone https://github.com/will-work-for-bitcoin/portfolio-tracker.git
cd portfolio-tracker
```

## Usage
```bash
python portfolio-tracker.py --add BTC 0.5 50000    # Add 0.5 BTC bought at $50k
python portfolio-tracker.py --list                 # View portfolio
python portfolio-tracker.py --json                  # Export as JSON
```
